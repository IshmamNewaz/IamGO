# MoreScopes 

# Normally Inside a package (Folders/directory) functions or variables are directly accissible. 
# But when accessing outside the package then the function or variables needs to be named with Capital Letter

* Explanation:
When calling a functions or variables are named in small letters it means it is private and can't be accessed outside the Package. To call outside the package it needs to be declared as Public, to do this the function or variable name needs to be written in Capital letter
